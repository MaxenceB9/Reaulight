# Raccourcis Clavier de l'Application

Bienvenue dans la documentation des raccourcis clavier pour notre application. Ces raccourcis sont conçus pour améliorer votre productivité et faciliter l'accès aux fonctionnalités principales.

## Raccourcis Généraux
- **Enregistrer** : `Ctrl + S`
  - Enregistre les modifications apportées au fichier actuel.

- **Enregistrer Sous** : `Ctrl + Shift + S`
  - Enregistre le fichier actuel sous un nouveau nom ou à un nouvel emplacement.

- **Importer un fichier** : `Ctrl + I`
  - Ouvrir un fichier projet créé par l'utilisateur ou un autre.
